## 🚀 How to Run Locally

You can run this project with any local server or simply open `index.html` in your browser:

### Option A: Python (Built-in)
```bash
python -m http.server 4173
```
Then visit: `http://localhost:4173`

### Option B: Node / npx serve
```bash
npx serve .
```

### Option C: Direct Browser Launch
Double-click `index.html` to open directly in Chrome, Edge, Safari, or Firefox.

This site is statically optimized with 0 build steps:
